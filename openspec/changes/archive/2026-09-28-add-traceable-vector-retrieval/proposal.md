## Why

第 3 课已经能登录、按班级隔离，并把讲义正文写进 `knowledge_entries`。本班材料还不能按一句话被检索，也没有可打开的出处。没有切片和班级过滤，后面的问答会要么编造依据，要么把其他班的内容泄漏出去。这一版先把「本班检索 + 可追溯出处」写成可验收规约，再按它实现。

## What Changes

- 教师上传成功后，把知识库正文切成切片，写入 `knowledge_chunks`；每条切片再做成向量，写入 Qdrant。向量主键等于切片主键。切片正文只存在 MySQL。
- 学生和教师都能在本班范围内检索。提供 `keyword`、`vector`、`hybrid` 三种模式，默认 `hybrid`。班级只来自登录会话，请求里的 `class_id` 一律丢掉。
- 每条命中必须能回到原文：材料标题、切片序号、字符区间、摘录，并能打开对应材料。摘录取自 MySQL 的切片正文。
- 所选模式过滤后没有候选时，返回「资料中未找到相关内容」，`hits` 为空。不得用低分切片凑数。跨班检索对外也是无命中，不返回 403。
- `POST /api/ask` 先对本班做混合检索，最多取 4 条；没有切片就不调用对话模型。有切片才生成带 `[1]` 标注的短回答。
- Compose 增加 Qdrant。浏览器只访问本站 `/api`，不能直连 Qdrant 或模型网关。

## Capabilities

### New Capabilities

- `knowledge-retrieval`：切片与索引、三种检索、出处标注、检索侧班级隔离、无依据不生成、Qdrant 与嵌入网关仅服务端可达。

### Modified Capabilities

- `auth-upload`：教师上传成功后必须触发切分与索引；种子材料启动时按自动窗口补齐索引。检索不改变登录、角色和跨班 404 的既有规则。

## Impact

- MySQL 新增 `knowledge_chunks`，并对 `chunk_text` 建 ngram 全文索引。
- Compose 新增 `qdrant` 服务，集合名为 `campusclaw_chunks`，度量用余弦。对外仍只映射 web 端口。
- 新增检索与问答接口，以及按策略重建索引的接口。前端材料页增加本班检索入口。
- api 只在服务端调用课程网关的嵌入接口和对话接口。密钥只放环境变量。

## Non-goals

- 不重做登录、角色、上传白名单和材料详情的 404 规则。
- 不做交叉编码器重排序，不引入 LangChain / LlamaIndex / Dify。
- 不做流式长对话（第 5 课）、作业批改、MCP、多副本和公网 HTTPS。
- 不把 Qdrant 端口映射到宿主，不把网关密钥下发到浏览器。
- 不做平台超级管理员，不按班级拆分多个 Qdrant 集合。
